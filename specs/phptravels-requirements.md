# PHPTRAVELS Website Requirements

The site supports public travel search, stays, flights, cars, visa services, AI trip planning, authentication, account access, booking, support, legal pages, localization controls, app links, and responsive workflows.

The application is a demo environment. Tests must use synthetic data only, avoid real payment information, and treat pricing, inventory, and bookings as non-production behavior.

## Core Requirements

- Load the public home page over HTTPS with primary navigation, services, featured properties, app promotion, footer, and demo notice.
- Validate stay and flight search fields and date relationships.
- Display results, empty states, errors, property details, and safe booking behavior.
- Provide authentication and protected-content handling.
- Expose support, policy, contact, currency, language, and app links.
- Maintain keyboard accessibility and usable mobile and desktop layouts.
- Never expose credentials, payment details, tokens, stack traces, or unauthorized account data.
